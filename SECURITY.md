# Security Policy

## Supported versions
The default branch is the supported development line.

## Reporting a vulnerability
Do not publish credentials, tokens, session strings, private messages, or exploit details in a public issue. Report security concerns privately through the repository owner's GitHub security reporting mechanism when available.

## Security expectations
- Keep all secrets outside source control.
- Use HTTPS in deployed environments.
- Restrict CORS to trusted origins.
- Rotate compromised API keys and Telegram sessions immediately.
- Use least-privilege, platform-approved permissions.
- Treat collected data as sensitive and apply appropriate retention and deletion controls.
